# 心证

一个中文庭审模拟游戏。你是辩护人，案子是真的。

单文件 HTML，打开就能玩：**https://lynch715.github.io/courtroom-simulator/**

---

## 这是什么

七个案子，全部改编自真实案件——许霆、赵春华、孙伟铭、于欢、昆山反杀、王力军、陆勇。
人名地名都做了化名，案情细节有改动，复盘页会告诉你原型是谁、现实里最后怎么判的。

一个案子分三幕：

1. **看卷宗**——一晚上的精力有限，读得细庭上才有底。给证据标三性，标对了庭上加成。
2. **和当事人沟通**——他不会主动说实话。信任攒够了他才开口，攒不够他就撒谎。
   每个案子的当事人都藏着一句谎，戳穿它要靠你阅卷时读到的那份材料。
3. **上庭辩护**——自由发言，想说什么说什么。法官有耐心值，说空话会被打断。

结果不是输赢，是**心证**：法官对每个争议焦点的内心倾向。复盘页会把你这场庭审
每一分心证的来路逐条摊开给你看，包括你没说出口的那些话。

## 怎么玩

打开网页就行。默认是**离线模式**，公诉人说预写好的台词，你的辩论按关键词判定——
摸机制手感够用了，但对方不会真的回应你。

想让它活过来，在设置里填一个 OpenAI 兼容接口：

- 接口地址 `https://api.deepseek.com`
- 模型 `deepseek-v4-flash`（快）或 `deepseek-v4-pro`（答得细）
- 你自己的 API Key

**密钥只存在你自己的浏览器 localStorage 里**，不会发到除了你填的那个接口之外的任何地方。

支持语音输入：按住说话（需要 HTTPS，本地 file:// 打开会自动降级成提示行，
让你用输入法的话筒键口述）。

## 项目结构

成品 `index.html` 是构建产物，**不要手改**。源码在 `src/`：

```
src/js/NN-name.js     按数字前缀顺序拼接，序号即加载顺序
src/data/cases/*.json 案件包，纯数据零函数
src/data/laws.json    11 部法律 156 个条文，纯本地
build.py              零依赖，先跑校验再拼装
```

改完跑 `python3 build.py` 出货。`python3 build.py --check` 只校验不出货。

三层红线：**数据层**（纯 JSON）/ **引擎层**（确定性，只走四个写入通道）/
**表演层**（LLM 只产出文本和提名，返回值必须过 `Engine.adjudicate()`）。
模型改不动分数，也改不动判决——`tools/hostile.js` 专门测这件事。

规范文档在 `docs/`，案件设计说明在 `cases/`，回归脚本在 `tools/`。

## 法条数据

`src/data/laws.json` 的条文取自 [lawtext/laws](https://github.com/lawtext/laws)。
