## c09《掏鸟窝的大学生》

**原型**：闫啸天案。人物、地名、单位均为化名。
**难度** 3　**律师费** 0.9 万　**预计** 22 分钟

### 破的是第 1 条：没有证人

前八个案子每一个都有证人环节。玩家已经形成肌肉记忆：问三个破绽，拿三四十分心证，
再出示一份辩方证据。这一案整个环节不存在——`cross` 里四格全是书证，`case` 里没有 `witness`。

拿掉一个环节就得补一个，否则这案子只是变短。补的是**一个前八案里等于废按钮的动作**。

### 补的东西：真能准的「申请调取」

c01 到 c08 的 `motions` 全部 `grant: false`。玩家试过一次申请、被驳回、扣四点耐心之后，
就再也不会用第二次了。这一案第一次有能准的：

```
{ "id": "m_hetero", "grant": true, "reveals": "e5", "patience": 2,
  "reply": "同案人的供述与本案犯罪数量的认定直接相关，且未随案移送。准许。…",
  "effect": {"issue": "i2", "v": 4, "why": "关键材料调取到庭"} }
```

配套的引擎改动（`62-act.js`）：`grant:true` 的申请不扣耐心，把 `reveals` 那份证据
`showEv()` 进卷宗，笔录里出一行「《…》调取到庭，已入卷」。
在线模式下模型只报「这是一个申请」，准不准由引擎按 `motions[].match` 重新匹配，
**并且用案件包里那句回应盖掉模型的话**——否则模型会自己演一句「准许」，而卷宗里什么都没多出来。

### 为什么这个申请是胜负手

司法解释：非法猎捕、出售隼类**十只以上**属情节特别严重，法定刑十年以上。
起诉认定十二只。差两只。

同案人贺文涛另案处理，他的讯问笔录**没有随案移送**——这句话写在 e3 讯问笔录的附注里，
一行，不显眼。那份笔录里有两件事：

- 北边那一窝四只是贺文涛一个人上的树，柯志远穿凉鞋上不去，在底下拿袋子
- 价是贺文涛定的，两千一百块柯志远只拿到八百

扣掉四只，十二变八，掉到十只以下，整个量刑档位塌下来。

**这份材料不在卷里。玩家必须自己想到要申请调取。** d3 的 `requires: "e5"`，
没调取到庭，这个论点在裁决层直接丢弃，一分不给。

### 另外压了第 3 条：精力不够读完

`energy: 8`，四份材料，细读全部正好 8 点——读完就一次「想一想」也没有了。
c08 是第一次有压力，c09 是第一次真的做不到面面俱到。

### 争点与权重

| | 争点 | 权重 | 单独打满落在哪一档 |
|---|---|---|---|
| i1 | 主观明知与取证合法性 | 40 | 40 → 五年 |
| i2 | 数量认定与罪刑相当 | 60 | 60 → 三年缓四 |

按 B10 补充二的检查动作算过：i2 单独打满是 60，落在最好那一档。
**这是有意的**——这个案子在现实里的争议本来就不在「他知不知道」，
而在「掏鸟窝配不配十年」。明知那条线打得再漂亮也翻不了案，
数量那条线打透了就能翻。玩家如果顺着当事人的意思去争明知，就是走错了路。

### 那句谎

他说「网上那些帖子不是我发的，宿舍里好几个人知道密码」。

戳穿它靠 e2：三张图的拍摄地点比对出来是他们宿舍，发帖 IP 是学生宿舍，
而且第二天有人问，他回了一句「就是燕隼 不是红隼 眼下那道黑纹不一样」——
这句话宿舍里没有第二个人说得出来。

**这个谎在真实案件里就是最站不住的一环**。法院正是据此认定明知。
如果玩家信了并在庭上复述，公诉人当场用他自己的帖子打脸，i1 −15，耐心 −10。

### 当事人想要的，和对的，不是一回事

他 21 岁，林业学院大二，最怕的不是坐牢是学籍。他求你做无罪辩护。

无罪辩护的乘数：`d1 ×1.35, d2 ×1.1, d4 ×0.9, d3 ×0.65, d5 ×0.5`。
一边主张他根本没犯罪，一边主张「就算犯了也才八只、判轻点」，法官两头都不信。

顺他的意，最好也就是五年；逆他的意做罪轻辩护，能到三年缓四。
**差的这两年，是你不听他的换来的。**

### 四条路线的实测（种子 23，离线路由）

| 打法 | 心证 | 判决 |
|---|---|---|
| 读透 + 三条秘密 + 申请调取 + 五个论点全讲（罪轻辩护） | 60 | 三年，缓刑四年 |
| 一模一样，只是没提那个申请 | 43 | 五年 |
| 顺着当事人做无罪辩护 | 48 | 五年 |
| 不读卷、不会见、庭上说空话 | −19 | 十年 |

**一个申请值 17 分心证和一整个量刑档。**

### 会见的信任标定

`trust0 30`，`turns 10`，门槛 40 / 55 / 68。
30 + 6×8 = 78，戳穿扣 5 得 73，第三条门槛 68，留一轮余量。实测走暖能问全三条（信任 79）。

注意这一案的秘密要**按门槛顺序问**：s1 谁上的树（40）、s2 钱怎么分（55）、s3 讯问那晚（68）。
提前问到高门槛的话题，他会说「还是算了」，那一轮就浪费了。这是有意的——
玩家得先把人聊热了再问要紧的。
