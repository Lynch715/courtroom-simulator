# 已知问题

施工规范第一条：发现既有问题记在这里，不在当前批次擅自修。

## 未修

1. **`#btnFile` 只在加载时按 `window.innerWidth` 决定显不显示**，窗口从宽拖到窄
   不会出现卷宗按钮。留给 B8 移动端走查。
2. **争点权重合计是 80 不是 100**。引擎按加权平均归一化，不影响判定，改成 100
   反而会动到心证数字。校验器只提醒不拦截。新案统一按百分比写。
3. **存档系统还没有**。目前只存设置（`xinzheng_cfg`），游戏进度不落盘，刷新即重来。
   随 B9 生涯外壳一起做，届时 `SAVE_VERSION` 从 1 起算。

**B14（起诉书 + 存档 + 法条抽屉）**
- **顶栏进设置会把正在打的这一局踢回事务所。** `$("#btnCfg").onclick = openCfg` 把
  点击事件对象当成 `first` 传了进去，事件对象是真值，于是按「开庭」走 `if(first) start()`。
  改设置这么常见的动作，代价是丢一局。改成 `()=>openCfg(false)`。
- **法条抽屉在独立应用模式下关不掉。** `#lawDrawer` 是 `position:fixed`，
  不吃 body 上的安全区 padding，整块贴着屏幕最顶上，「关闭」正好压在状态栏底下，
  手指点下去被系统吃掉。而手机上抽屉是满屏的，没有「外面」可点，也没有 Esc 键——
  唯一的出口失效，玩家就被困住了。抽屉自己垫安全区，关闭按钮给到 44×44，
  另外补三条退路：Esc、点抽屉外面（宽屏）、底部一条「收起法条」（窄屏）。
  `.mask` 和 `#toast` 是同一类问题，一并垫了。
- **起诉书只有一句话。** 玩家点开案子，不知道被告人叫什么、多大、干什么的、
  为什么被抓、检察院要判他多少。八个案子逐个补 `indictment`：
  机关 / 文号 / 被告人 / 指控事实 / 证据 / 本院认为 / 量刑建议，五百到七百六十字，
  照公文格式排。默认折起来，点「读全文」展开。
- **没有任何存档入口。** 存档一直在存，但想重开一局只能清浏览器数据。
  设置里加一栏：当前这一局（显示案名、阶段、存档时间，可「重开这一局」）和
  生涯记录（显示打完几个、声誉良心钱，可「全部清空」）。两件事分开，各自二次确认。

**B13（手机化 + 流程返修）**
- **「去法院」按钮点了去看守所。** 阅卷结束后引擎调的是 `startMeet()`，
  三个出口按钮却全写着「去法院」，八个案子的 `investigation.outro` 也全是
  「天亮了。该去法院了。」——玩家按流程走一遍，第一个岔路口就被骗了。
  改成 `nextStopLabel()` 按 `CASE.meeting.place` 现算（看守所 / 事务所 / 会见室），
  八份 outro 逐个改写成真正的下一站。
- **「去法院」原本是个 `setTimeout`。** 会见定完策略 900 毫秒后自己跳进法庭，
  玩家没有一个「我现在要开庭了」的动作。加 `goCourtGate()`：结算这一趟拿到几条
  他亲口说的事、庭上有几个论点、做什么辩护，然后一个大按钮「去法院」。
- **卷宗页没有案情介绍。** `case.brief` 一直存在，但只喂给模型，玩家看不到。
  加 `briefHTML()` / `#briefSect`，起诉书那一块放在左栏最上面。
- **离线会见的 low / press 话池全是两到七个字。** 「嗯。」「……」「我说了。」——
  戒备不等于没词。八个案子逐个重写，每池留一两句短的当节奏，其余给身上的东西、
  屋里的东西、别人怎么说他。长度从 2~14 字提到 2~38 字。
- **单文件版会把 `art/source` 和 `art/delivery` 一起吃进去。** `scan_art()` 排了这两个目录，
  `embed_art()` 没排，于是 `--embed` 出来一个 257 MB 的 html。补上同样的过滤，现在 12 MB。
- **宽屏事务所页左对齐**，1440 下右半边空一大块，像没加载完。`.office` 加 `margin:0 auto`。

**B13 新增（不是修 bug）**
- 手机端禁缩放：viewport 加 `user-scalable=no`，另外自己拦 `gesturestart` 和双击
  （iOS 10 起 Safari 不认 viewport 里那句），CSS 上 `touch-action:manipulation`，
  窄屏输入框强制 16px——不到 16px 的话 iOS 对焦时会自动推近，而缩放已经禁了，推近就退不回来。
- 桌面图标 + PWA：`icons/`（180/192/512/maskable-512/favicon-64）、`manifest.webmanifest`、
  `display:standalone`。主题色跟着亮暗主题走（`applyTheme()` 里重写 `<meta name=theme-color>`），
  安全区只垫上、左、右——底下那条 `#tabbar` 自己已经垫过了，垫两回会空出一块。
  单文件版由 `inline_icons()` 把图标和 manifest 转成 data: URI 内嵌。

**B11 后半（第六案带出来的）**
- **离线会见把信任门槛按「说这句话之前」的信任算，实际加成却是这句话带来的。**
  `applyMeet` 是先加信任、再判秘密；`offlineMeet` 却拿旧值过滤 `reveals`，
  于是同一句话在离线比数据写的多卡一档——**每个案子的第三个秘密都差一口气**，
  玩家看到的是「这个我不想讲」，可他其实已经够格了。c03/c04/c05/c06 的 s3 全中招。
  现在按 `S.trust + 语气加成 + 承诺加成` 之后的值判。修完四个案子的 s3 都能问出来。

**B11（相对 B10）**
- **新增称谓表 `case.lex`**（详见 `src/data/cases/_schema.md` B11 变更）。引擎里
  「审判长」「本庭」「退庭」「判决」「质证」这类词原来写死在代码里，现在统一从
  `L(key)` 取，案件包覆盖几条就能把同一套流程换成另一种场合。c05 是检察院的
  不起诉听证，用的就是这个；民事和行政那五个案子（16–20）也要靠它。
- **离线应答池改成带占位符**（`{lawyer}`、`{court}` 等），跟着 lex 走。
  案件包还可以用 `case.offlinePool.<类名>` 整池覆盖。
- **阶段条的五个格子改成从 lex 取名**，所以 c05 显示的是「阅卷 / 会见 / 出示证据 /
  听证发言 / 评议决定」。
- **行为不变**：c01~c04 不写 `lex`，走默认值，回归探针三条路线与切片逐字一致。

**B10 后半（第四案带出来的）**
- **存档只有在「存的正好是默认案件」时才续得上。** `savedGame()` 拿 `d.caseId` 和当前
  绑定的 `PACK.id` 比，可刷新之后 `PACK` 还是 `CASES[0]`，所以存了 c02/c03/c04 再刷新，
  一律被当成作废存档，直接回事务所——进度就没了。现在只校验 `SAVE_VERSION` 和
  「这个案件包还在不在」，`start()` 里先 `useCase(d.caseId)` 再问「要接着打吗」。
- **证人环节的「出示证据」按钮开关看错了字段。** 原来是 `w.contradicts`，c01~c03 里
  它和要出示的那份证据恰好同一份，c04 不是（证言抵触的是控方接处警记录，要出示的是
  辩方借款凭证），按钮就永远不出现，`requires: e4` 的论点变成死内容。
  改成看 `options.find(v==="show").reveal`。
- **论点因为前置证据没出示被丢掉，以前记成「发言空泛」扣 3 分。** 玩家看不出自己漏了哪一步。
  现在审判长会说「辩护人主张的这一节，相应证据没有出示。《X》不在庭上。」，耐心 −2。
- **庭上引用当事人谎话被戳穿之后，还会再挨一刀「空泛」。** 那句话不空泛，它是假的，
  两个罚名不该叠。现在 quotedLie 触发的这一轮不再走 vague/sound。
- **判决档位和结局档位可能对不齐。** 结局在 `epilogueOf()` 里按 50/20/0 分段写死，
  案件包的 `verdicts[].min` 如果错开，就会出现「判五年，配无罪的结局文案」。
  校验器新增提醒，c03（原 50/25/5）和 c04 都已对齐到 50/20/0。

**B10（相对 B9）**
- **问出证人破绽，不再直接把论点「立住」。** 以前 `weakSpots[].grants` 走 `hitPoint()`，
  论点按 `gv`（8~10 分）当场记成立住，之后再也不能在辩论里争。结果是问对了问题反而
  比不问少拿分——辩论里同一个论点值 20~40。现在 `grants` 只做两件事：按 `gv` 加心证、
  把论点 id 记进 `S.witGrants`，裁决层给它 ×1.25。**事实是你问出来的，理由还得你自己讲。**
  受影响的是 c02 的鉴定人和 c03 的交警：老玩法里那两个论点白拿，现在得在辩论里说一遍。
- **单次发言的增益上限不再「打折立住」。** `ADJ.maxGain`（25）截断时，如果一个论点只能
  拿到不足应得分数 `keepRatio`（0.6）的零头，就整个不立，记 `本次说不透，留到下一轮`，
  留给玩家下一轮专门讲。以前会以 4 分把一个 35 分的论点消耗掉，认真准备的第二句话就废了。
- **离线路由：讲对了但这一点已经立住，判为「在理但无新论点」而不是「空泛」。**
  以前 `offlineAct` 直接跳过已命中的关键词，一句站得住的重复论证落到 `penalties.vague`
  扣 3 分心证。现在走 `penalties.sound` +2，法官台词也换成「这一点辩护人讲过了，记录里有」。
- c03 的三条辩护策略原来没写 `mul`，选哪条只影响信任和台词，不影响判定。已补齐。

## 有意为之的行为差异

**B0（相对切片）**
- 顶栏案名改从 `PACK.meta.headerLine` 取，字符串完全相同。
- `localStorage` 的 key 换成 `CFG_KEY` 常量，值仍是 `xinzheng_cfg`，旧存档兼容。
- 页面 `<title>` 从「心证 · 庭审垂直切片」改成「心证 · 庭审模拟」。

**B10（相对 B9）**
- 第二个案子 c02（射击摊上的九支枪，赵春华案原型）写完了，schema 一个字段没改就跑通，
  只补了一个 `finalWordRounds`。
- **修了一个设计缺陷**：论点栈空了辩论就结束，导致「在法庭调查阶段就把控方打垮」的玩家
  反而没机会讲完自己的论点。现在辩论终结前审判长会问「你还有什么要说的」，
  给最多三轮补充发言。c02 实测：心证从 21 变成 31，四个论点全立住。
- 接案页改成「没打过的排前面，打过的接着排，最多三张」，之前打过的案子会整个消失。
- c02 缺两张图（周秀兰、鉴定人屈志远），走 SVG 占位，不影响玩。

**B9（相对 B8）**
- **开局变成事务所一屏**：三轨、上一案余波、接案。所有测试脚本都加了「先点案件卡」这一步。
- 案件可以切换了（`PACK`/`CASE` 从 const 改成 let + `useCase(id)`），为 B10 的多案做准备。
- 存档：中途退出重进能接上当前那一幕。笔录只留摘要，续上时不重播全文。
- **踩了一个暂时性死区**：`useCase()` 在脚本最前面就调 `resetArtCache()`，
  而缓存变量用 `let` 声明在后面的模块里，一碰就抛「Cannot access before initialization」。
  改成 `var`。这类跨模块的启动期调用要留神。
- 案件池只有 1 个时接案页就只列 1 个，池满 3 个之后自动变成 3 选 1。

**B8（相对 B7）**
- P0 那 19 张图接进去了：三幕转场、笔录小像、审判长神态小窗、会见立绘、
  阅卷的证据照片、关键时刻的立绘滑入。
- **补图之后要重新构建一次**（`python3 build.py`）。构建时会扫 `art/` 记下有哪些图，
  没扫到的直接画占位、连请求都不发——这样 `art/` 空着的时候控制台一条报错都没有。
  代价就是补图要重建，换来的是干净的控制台，值。
- 表情差分（`<key>_frown` / `<key>_grim`）代码已经在找了，没出图就自动用原图。
- `art/source/`（33MB 的 PNG 原图）和 delivery 里的 zip、contact sheet 已进 .gitignore，
  仓库里只留 1.9MB 的 webp。

**B7（相对 B6）**
- 法条速查：11 部法 156 条 + 35 条罪名别名，纯本地零外网。
  笔录和证据全文里的条文号会点亮，点开即看原文。
- 「非法持有枪支」这类整串搜不到的（原文是「非法持有、私藏枪支」），拆词再搜一遍。
- 「高空抛物」这类罪名不在正文里的，走别名表。

**B6（相对 B5）**
- 语音输入接上了。文字和语音是并排的两个等宽按钮，不是输入框角落的小话筒。
  六处输入框都能用：质证补充理由、证人发问、辩论、会见、插话、阅卷批注。
- **Chromium 把 `file://` 也算 isSecureContext**，但它照样不给麦克风。所以能力检测必须
  单独判 `location.protocol === "file:"`，只看 isSecureContext 会漏。
- 手机端布局重排：原来是 grid 两行，只够三栏庭审用；加了阅卷和会见之后行高算不出来，
  整个 main 塌成 0 高。改成竖排 flex。
- **修了一个从 B4 起就存在的模板 bug**：改「出庭人员」为数据驱动时，字符串切片吃掉了一个
  `</div>`，`.col.left` 没闭合，把中栏和右栏都吞了进去。桌面和手机都是坏的，
  但所有测试都过——因为它们按 id 查元素，没人看布局。
  探针现在加了一条结构自检：三栏必须是 main 的直接子元素。

**B5（相对 B4）**
- **异议不能背轮次了**。原来第三轮固定讲「数额特别巨大」，提「与本案事实无关」必成立；
  现在他第三轮说什么取决于你前面驳倒了什么，同一个异议可能就不成立。这是导演器的目的。
- 辩论轮次浮动（1–5 轮），不再固定三轮。
- 证人环节从三选一变成循环：发问、出示证据、结束，想怎么组合都行。
- 修了一个内容 bug：论点「民事救济」的离线关键词里有「民法」，
  玩家说「报最高人民**法院**核准」时会被误判成同时立住了民事救济。校验器现在会拦这类误伤。
- 修了一个代码 bug：`find(x => x.id === S.argDropped.shift())` 把 shift 写进了 find 的回调，
  数组每比对一个元素就被弹掉一个，「公诉人没有再提…」这句提示永远不出现。

**B4（相对 B3）**
- **判定数字变了，而且是故意的**：会见结尾定的辩护策略会给论点上乘数
  （无罪辩护让 d2/d3 ×1.15、d4 ×0.7，罪轻辩护反过来，程序辩护让质证 ×1.3）。
  同一套打法，选无罪辩护是 i1 +22 / i2 +17，选罪轻辩护是 i1 +17 / i2 +23。
  从 B4 起，回归探针比对的是「有没有崩、能不能走完、数字往不往预期的方向动」，
  不再是「一个数都不许变」。
- 出庭人员列表改成读 `cast` 渲染，不再是写死的 HTML。当事人那一栏在会见后会换一句话。
- 阶段条变五格。

**B3（相对 B2）**
- **开局改了**：现在从开庭前一晚的阅卷开始，读完（或直接走人）才进法庭。
  阅卷可以整段跳过，跳过后庭审的判定与 B2 完全一致（回归探针三条路线全绿）。
- 阶段条从写死的三格改成按 `PHASES` 渲染，现在是四格。B4 会插进「会见」变五格。
- 阅卷阶段左栏不显示心证数值，只显示「待庭审」——开庭前你不可能知道法官怎么想。
- 标错三性不罚，跟没标一样。这是有意的：阅卷是你自己的事，错了只是浪费精力。

**B2（相对 B1）**
- **法官的固定台词换成了应答池抽取**，同一个情境每次说的不一样。判决和心证不受影响
  （回归探针三条路线的判定全绿，只有台词行有差异）。
- 随机数改成可播种：`Engine.seed(42)` 之后整局可复现，测试脚本靠这个比对笔录。
  正常游玩时种子为 0，走真随机。
- 辩论输入框现在接受任何话——申请、发问、骂人都行，各有各的代价。
- 新增插话入口（笔录下方「辩护人，我有话说」），任何阶段可用，被禁言后收起。

**B1（相对 B0）**
- **卷宗栏的证据出场时机变了**。切片里只要质证开始，所有控方证据一起变亮；
  现在按 `revealAt` 逐份出场——公诉人出示到哪份，哪份才亮。这是修正，不是回归。
  心证、判决、笔录都不受影响（回归探针三条路线全绿）。

- 结案时把声誉和良心写进 `S.career`（此前只在复盘页显示，不落状态）。
  流水按频道分开（心 / 耐 / 涯），复盘页和右栏只显示心证频道，所以显示没变。
