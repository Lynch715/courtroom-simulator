# 《心证》美术资源清单 v1

> 用途：交给出图模型（GPT / 即梦 / MJ 均可）批量产出。出完按本文**文件名**放进 `模拟律师/art/` 对应子目录，游戏自动生效，**不需要改代码**。
> 图标类（阶段图标、天平、证据类型小图）全部用原创 SVG 在 HTML 里画好，**不需要出图**。
> 一期总量：**立绘 40 + 场景 16 + 证据卡 12 = 68 张**。其中标 **P0** 的 18 张出完就能开局，剩下的补一张生效一张。

---

## 一、接入方式

### 1.1 目录结构

```
模拟律师/
├─ 心证.html
└─ art/
   ├─ cast/    40 张 人物立绘（透明底）
   ├─ scene/   16 张 场景图（不透明）
   └─ ev/      12 张 证据卡（不透明）
```

### 1.2 取图顺序（代码里做好三层回落）

1. `ART_DATA[key]` —— 内嵌 base64（想要真·单文件时用）
2. `art/<key>.webp` —— 文件夹模式（**推荐，改图不用动 HTML**）
3. 都没有 → 回落到内置原创 SVG 占位（不报错、不破版）

```js
const ART_BASE = "art/";   // 想内嵌就设成 ""，然后往 ART_DATA 里填 base64
```

**注意**：`file://` 双击打开时，`art/` 相对路径的 `<img>` 能正常加载（图片不受 CORS 限制），所以文件夹模式本地也能用。只有 `fetch` JSON 才受限。

### 1.3 通用技术规格

| 项 | 要求 |
|---|---|
| 格式 | `.webp`，质量 82–88。出图是 PNG，用 `cwebp -q 85 in.png -o out.webp` 转 |
| 立绘背景 | **纯透明**（PNG 带 alpha 再转 WebP）。不要白底、不要渐变底、不要投影 |
| 场景/证据卡背景 | 不透明，四周可压暗 |
| 色彩 | 见 1.4。**不要偏亮、不要偏饱和**，游戏底色是 `#11151A` |
| 文字 | 图里**一个字都不要有**。证据卡上的"文字"必须处理成不可读的墨痕/虚化横线，见第四节 |
| 单张体积 | 立绘 ≤ 130KB，场景 ≤ 280KB，证据卡 ≤ 160KB |
| 命名 | 全小写，下划线分隔，与本文第二/三/四节的 key 完全一致 |

### 1.4 风格锚点（所有图必须一致）

《心证》的调子和《模拟明星》**完全相反**：那边是暖金红毯，这边是冷白顶光下的木色与铜色。

**统一风格前缀（每条提示词前面都粘这一段）：**

```

Cool neutral overhead lighting (5200K) with soft fill from camera left, deep
umber wood tones (#4A3527), muted brass accents (#B99245), desaturated
steel-blue shadows, near-black background (#11151A). Restrained, serious mood.
Shallow depth of field, 50mm lens look, fine film grain, no HDR glow, no bloom.
East Asian cast, natural realistic faces and skin texture, restrained expressions,
no smiling. No text, no watermark, no logo, no subtitles, no signature.
```

**统一反向提示词（每条都粘）：**

```

```

## 二、人物立绘（40 张 · `art/cast/`）

- **尺寸 900×1200**，透明背景
- **半身，腰以上，四分之三侧身**，人物占画面高度 85%，头顶留 6% 余量
- 视线略偏离镜头（**不要正视观众**），神情克制，不笑

```
Half-body portrait, three-quarter view, waist up, fully transparent background,
subject occupies 85% of frame height, eyes looking slightly off-camera,
neutral serious expression, no smile, single subject only, no props in hand
unless specified.
```

## 四、证据卡（12 张 · `art/ev/`）

证据卡是玩家点开卷宗时看到的图，**是这个游戏最能出沉浸感的一类素材**——你在质证的东西终于长了个样子。

### 4.1 通用规格与最重要的一条

- **尺寸 1200×900**，不透明
- **俯拍桌面视角**，深色木桌或深灰台面，单一冷光源从左上打下，右下有自然阴影
- **所有文字必须不可读**：处理成灰色横线、失焦墨痕或被浅景深化开。提示词里统一加：

```
All printed text is rendered as illegible grey horizontal lines and soft ink
smudges, completely unreadable, out of focus. No actual letters or characters
anywhere in the image.
```

这既满足"图里不能有字"的硬规，又让它一眼就是一份文件。

**通用提示词后缀：**

```
Top-down flat-lay on a dark walnut desk surface, single cool key light from
upper left, soft natural shadow to lower right, shallow depth of field,
document occupies 80% of frame, slight paper texture and handling creases.
```

## 六、出图与转换流程

1. **一个会话出一组**。同组（比如所有法官）在同一次会话里连续生成，风格一致性最好。换组时重新粘一次风格前缀。
2. 立绘出图时如果模型不支持透明背景，就用**纯品红 `#FF00FF` 背景**出，再抠：
   ```bash
   magick in.png -fuzz 12% -transparent '#FF00FF' out.png
   ```
3. 统一转 WebP：
   ```bash
   cd art/cast && for f in *.png; do cwebp -q 85 "$f" -o "${f%.png}.webp"; done && rm *.png
   ```
4. 体积超标的用 `-q 78` 再压一次；场景图可先 `magick in.png -resize 1920x1080 in.png`。
5. **验收**：把整个 `art/` 目录清空，游戏必须零报错全流程可玩（走 SVG 占位）；然后逐张放回，每放一张刷新看是否生效、是否与暗色底协调。
