# 《心证》美术资源清单 v2

> 取代 v1。改动：补齐**第一幕 阅卷**与**第二幕 会见**所需素材；按 20 个真实原型案件补人物与专属证据卡；新增「表情差分」的明确规格。
> 用途：交给出图模型（GPT / 即梦 / MJ 均可）批量产出。出完按本文**文件名**放进 `art/` 对应子目录，游戏自动生效，**不需要改代码**。
> 图标类（阶段图标、天平、精力点、信任条、证据类型角标）全部用原创 SVG 在代码里画，**不需要出图**。

**一期总量：立绘 48 + 场景 21 + 证据卡 20 = 89 张。** 标 **P0** 的 24 张出完就能把第一个案子的三幕完整跑起来。

## 一、接入方式

### 1.1 目录结构

```
art/
├─ cast/    48 张 人物立绘（透明底）
├─ scene/   21 张 场景图（不透明）
└─ ev/      20 张 证据卡（不透明）
```

### 1.2 取图顺序（代码里做好三层回落）

1. `ART_DATA[key]` —— 内嵌 base64（`build.py --embed` 时自动填充）
2. `art/<子目录>/<key>.webp` —— 文件夹模式（**推荐，改图不用重新构建**）
3. 都没有 → 内置原创 SVG 占位（不报错、不破版）

图片加载失败静默回落，所以**可以一张一张往里补，补一张生效一张**。

### 1.3 通用技术规格

| 项 | 要求 |
|---|---|
| 格式 | `.webp`，质量 82–88。出图是 PNG，用 `cwebp -q 85 in.png -o out.webp` 转 |
| 立绘背景 | **纯透明**。不要白底、不要渐变底、不要投影 |
| 场景/证据卡 | 不透明，四周可压暗 |
| 色彩 | 见 1.4。**不要偏亮、不要偏饱和**，游戏底色 `#11151A` |
| 文字 | 图里**一个字都不要有**。证据卡上的"文字"处理成不可读墨痕，见第四节 |
| 体积 | 立绘 ≤130KB，场景 ≤280KB，证据卡 ≤160KB |
| 命名 | 全小写下划线，与本文 key 完全一致 |

### 1.4 风格锚点（所有图必须一致）

《心证》的调子和《模拟明星》完全相反：那边是暖金红毯，这边是冷白顶光下的木色与铜色。

**统一风格前缀（每条提示词前面都粘这一段）：**

```
Cinematic photorealistic still from a contemporary mainland-China courtroom drama.
Cool neutral overhead lighting (5200K) with soft fill from camera left, deep
umber wood tones (#4A3527), muted brass accents (#B99245), desaturated
steel-blue shadows, near-black background (#11151A). Restrained, serious mood.
Shallow depth of field, 50mm lens look, fine film grain, no HDR glow, no bloom.
East Asian cast, natural realistic faces and skin texture, restrained expressions,
no smiling. No text, no watermark, no logo, no subtitles, no signature.
```

**统一反向提示词（每条都粘）：**

```
Negative: text, letters, chinese characters, watermark, logo, signature, subtitles,
cartoon, anime, illustration, 3d render, cgi, plastic skin, beauty filter,
oversaturated, bright daylight, white background, HDR, lens flare,
western faces, powdered wig, white collar tabs, jury box, american flag,
courtroom sketch style, extra fingers, deformed hands, blurry face, crowd.
```

- **900×1200**，透明背景
- **半身，腰以上，四分之三侧身**，人物占画面高 85%，头顶留 6%
- 视线略偏离镜头（**不正视观众**），神情克制，不笑

**通用提示词后缀（每条都加）：**
```
Half-body portrait, three-quarter view, waist up, fully transparent background,
subject occupies 85% of frame height, eyes looking slightly off-camera,
neutral serious expression, no smile, single subject only.
```

## 四、证据卡（20 张 · `art/ev/`）

证据卡是玩家在**第一幕阅卷**时反复看的东西，也是这个游戏最能出沉浸感的一类素材——你要质证的那份笔录，终于长了个样子。

### 4.1 通用规格与最重要的一条

- **1200×900**，不透明
- **俯拍桌面视角**，深色木桌或深灰台面，单一冷光源从左上，右下自然阴影

**所有文字必须不可读**，提示词统一加：
```
All printed text is rendered as illegible grey horizontal lines and soft ink
smudges, completely unreadable, out of focus. No actual letters or characters
anywhere in the image.
```
这既满足"图里不能有字"，又让它一眼就是一份文件。

**通用提示词后缀：**
```
Top-down flat-lay on a dark walnut desk surface, single cool key light from
upper left, soft natural shadow to lower right, shallow depth of field,
document occupies 80% of frame, slight paper texture and handling creases.
```

## 六、出图与转换流程

1. **一组一个会话**。同组（比如所有法官）连续生成，风格一致性最好。换组时重新粘一次风格前缀。
2. 立绘若模型不支持透明背景，用纯品红 `#FF00FF` 出，再抠：
   ```bash
   magick in.png -fuzz 12% -transparent '#FF00FF' out.png
   ```
3. 批量转 WebP：
   ```bash
   cd art/cast && for f in *.png; do cwebp -q 85 "$f" -o "${f%.png}.webp"; done && rm *.png
   ```
4. 超标的用 `-q 78` 再压；场景图先 `magick in.png -resize 1920x1080 in.png`。
5. **验收**：清空整个 `art/` 目录，游戏必须零报错全流程可玩（走 SVG 占位）；再逐张放回，每放一张刷新看是否生效、是否与暗底协调。
