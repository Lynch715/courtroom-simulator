## 三件必须守住的事

1. **文件名就是 key**，一个字都不能差。放进 `art/cast|scene|ev/` 对应目录，扩展名 `.webp`。
   放错名字游戏找不到，会静默回落成 SVG 占位——不报错，但你也看不出哪里错了。
2. **补完图要重新构建一次**：`python3 build.py`。
   构建时会扫一遍 `art/`，把有哪些图记进产物；没扫到的直接画占位，连请求都不发。
   这是为了让 `art/` 空着的时候控制台一条报错都没有，代价就是补图要重建。
3. **人物立绘要真的透明通道**，不是白底也不是灰底。P0 那批是对的，照那个来。

## 尺寸与转换

| 类 | 尺寸 | 上限 |
|---|---|---|
| cast 人物 | 900×1200，透明 | ≤130KB |
| scene 场景 | 1920×1080，不透明 | ≤280KB |
| ev 证据卡 | 1200×900，不透明 | ≤160KB |

```bash
cd art/cast && for f in *.png; do cwebp -q 85 "$f" -o "${f%.png}.webp"; done
```

超标的用 `-q 78` 再压一次。

## 表情差分怎么出

命名 `<原key>_frown.webp`（皱眉／不悦）和 `<原key>_grim.webp`（凝重／受挫）。

**在生成原图的同一次会话里接着出**，只改表情——服装、发型、光位、构图必须和原图一致，
否则切换的时候会跳。

代码已经在找这两个文件了：审判长的神态小窗跟着耐心值换脸（>55 用原图，30–55 用 frown，
<30 用 grim），关键时刻的立绘滑入也会带表情。**没出这两张就自动用原图**，所以出一张生效一张。

## 验收

出完放进目录、重新构建，然后：

- 清空整个 `art/` 目录构建一次，游戏必须零报错全程可玩（全走 SVG 占位）
- 放回去再构建，逐张刷新看是否生效、跟深色底（`#11151A`）搭不搭
- 人物立绘在 38px 的小像里也要认得出是谁——脸别太小、别偏出画面
