## 一、游戏循环改为三幕

这是 v2 最大的结构性改动。原来"一个案子 = 一场庭审"，现在"一个案子 = 三幕 + 复盘"。

```
接案（3 选 1）
   │
   ├─ 第一幕 · 阅卷      精力预算 8 点，读证据、标疑点、问自己
   │        ↓ 带走：疑点标记 S.marks
   ├─ 第二幕 · 会见      10 轮自由对话，LLM 演当事人，问出他不肯说的
   │        ↓ 带走：已知真相 S.known、信任度、辩护策略
   ├─ 第三幕 · 庭审      举证质证 → 法庭辩论 → 评议宣判
   │        ↓
   └─ 复盘：心证流水 + 没说出口的话 + 案件原型延伸阅读
```

**三幕不是三个独立小游戏，是一条因果链**——这是整个设计里最要紧的一句话：

> 你没在阅卷时读到那份运维日志 → 会见时就戳不穿当事人的那句谎 → 庭上你引用了他的谎话 → 公诉人当场打脸 → 心证暴跌。

一条链把三幕焊死。玩家输掉一场庭审，能倒推回是哪一步偷的懒。

### 1.1 第一幕 · 阅卷

**界面**：卷宗桌面（俯拍场景图打底），左侧证据列表，中间证据全文，右侧你的批注本。

**核心机制：精力预算 + 疑点标记**

- 精力 8 点。**粗看**一份证据 1 点（只给 `note` 摘要），**细读** 2 点（给 `detail` 全文，才可能看出瑕疵）。证据通常 6–9 份，读不完，必须取舍。
- 细读后可对该证据打三种标记：`真实性存疑` / `合法性存疑` / `关联性存疑`，另可写一条自由批注。
- **标对了**：庭上质证这份证据时进入"有备而来"状态——分值 ×1.3，且审判长的回应不同（"辩护人显然看过卷"）。
- **标错了**：没有惩罚。阅卷是你自己的事，错了只是浪费了精力点。
- **漏了**：那份证据在庭上只能临场应对，没有加成。

**LLM 参与（轻）**：细读一份证据时可以点"想一想"（每案限 3 次，各花 1 点精力），模型以**你的内心独白**口吻给一段分析。规则：**只给方向不给答案**——"这份笔录只有一名侦查人员签名，取证程序上或许有话说"，而不是"这里可以提合法性异议，能加 12 分"。

**产出**：`S.marks{evId: [flags], notes:[]}`、`S.read:Set`（读过哪些，决定会见时能戳穿哪些谎）。

### 1.2 第二幕 · 会见当事人（LLM 驱动的核心新玩法）

**界面**：看守所会见室（隔玻璃，刑事）或律所会议室（民事）。当事人立绘在左，对话在右，下方是信任度条和剩余轮次。

**当事人不会跟你说实话。** 这是这一幕的全部设计前提，也是所有律师题材作品里最真实的一点。

案件包里每个当事人带三样东西：

```js
client:{
  castId:"civ_m_20s_guard",
  trust: 30,                       // 初始信任度 0-100
  turns: 10,                       // 会见轮次预算
  persona:"…", voice:"…",
  secrets:[                        // 他不主动说的事
    {id:"s1", trust:45, topic:"第一次取款的经过",
     truth:"第一次确实是机器吐多了，他当场愣了三分钟",
     grants:"d1", value:"庭上可用于论证首次行为无故意"},
    {id:"s2", trust:70, topic:"他为什么没有报警",
     truth:"他给银行打过一次电话，占线，之后就没再打",
     grants:"d5"}
  ],
  lies:[                           // 他会主动说的假话
    {id:"l1", claim:"我一次都没意识到机器有问题",
     bustBy:"e3",                  // 需要你阅卷时读过这份证据才能戳穿
     onBust:"……行吧。我跟老王提过一嘴，就随口一说。",
     ifBelieved:"trapped"}         // 你信了 → 庭上引用会被公诉人打脸
  ]
}
```

**信任度的涨落**（前端判定，模型只演）：

| 你的行为 | 信任 |
|---|---|
| 表达对他处境的理解、说明程序、告诉他后果 | +6 |
| 问开放式问题、让他自己讲 | +4 |
| 像审讯一样连续质问 | −8 |
| 用证据戳穿他的谎（时机对：他刚说完谎） | −5 但**解锁真相** |
| 用证据戳穿他的谎（时机错：他已经开始配合） | −12，无解锁 |
| 承诺你做不到的事（"我保证你无罪"） | +10 当场，但**良心 −5**，且庭上败诉时结局更惨 |

**秘密解锁**：`trust ≥ secret.trust` 且你的提问被判定为触及该 `topic` → 他说出真相 → `grants` 的论点在庭上**直接可用且分值 ×1.2**（因为你知道细节，不是在猜）。

**谎言机制（三幕联动的关键）**：
- 会见中当事人会主动抛出 `lies` 里的一条。
- 你**读过** `bustBy` 那份证据 → 输入框出现一个"出示卷宗中的记载"的快捷动作，用了就戳穿，他松口。
- 你**没读过** → 你只能信或不信。信了并在庭审中引用（模型检测你的庭上发言是否复述了 `claim`）→ 公诉人当场用那份证据打脸，**心证 −15，法官耐心 −10**，笔录里出现全场最难堪的一句。
- 你什么都没说 → 无事发生，但你少了一条论点。

**辩护策略确认（这一幕的结尾，也是良心轨的第一次考验）**：

会见结束时三选一：**无罪辩护** / **罪轻辩护** / **程序辩护**。三条路影响庭上论点权重、公诉人的应对、以及判决档位的分布。

关键设计：**当事人可能不同意你**。他想认罪求个轻判（他怕），你想做无罪辩护（你觉得他真没罪）。

- 顺他的意 → 信任 +10，庭上他配合；但如果你本可以打赢无罪，复盘页会告诉你这件事，良心 −8
- 逆他的意 → 信任 −15，庭上他的最后陈述可能拆你的台；打赢了良心 +12，打输了他要多坐几年，良心 −15
- **这里没有正确答案。** 这个游戏的重量就在这种地方。

**LLM 参与（重）**：全自由对话。模型拿到当事人人格卡 + 已解锁/未解锁的 secrets + lies + 当前信任度，演他。前端负责：判定提问触及了哪个 `topic`（同庭审的 `weakSpots` 机制）、信任度加减、秘密解锁、谎言戳穿。**模型不决定任何数值。**

### 1.3 第三幕 · 庭审

维持 v1 的设计（意图路由 / 论点栈 / 法官耐心 / 防注入），新增三处与前两幕的接口：

1. 质证时读取 `S.marks`，标对的证据进入"有备而来"
2. 辩论时 `S.known` 里的秘密解锁额外论点，且分值 ×1.2
3. 若你信了谎话并在庭上复述 → 触发打脸事件

### 1.4 幕间：律所

三幕之间插一屏"律所办公室"，用来放：接案选择、声誉/金钱/良心三轨、上一案的余波（当事人家属来信、同行评价、媒体找上门）。轻量，一屏搞定。

## 二、20 个案子：真实大案为原型

### 2.1 为什么值得这么做，以及怎么做才安全

真实名案是这个游戏最大的卖点——**"许霆案""于欢案""快播案"这几个字本身就是流量**，而且它们之所以出名，正是因为争点清楚、社会讨论充分、法学界反复推演过，天然就是好关卡。

但要处理好两件事：

**其一，法律上。** 裁判文书属于《著作权法》第五条排除的"司法性质的文件"，不受著作权保护，可以自由参考。法律法规同理。真正的风险不在著作权，在**对具体个人的再消费**——尤其是被害人及其家属。

**其二，观感上。** 让玩家扮演律师去替一个真名真姓、被害人还在世的被告人辩护，容易变成对当事人的二次伤害。

**采用的方案：骨架真实，姓名虚构，原型公开。**

| 层 | 做法 |
|---|---|
| 案情骨架、争点、法条、判决档位 | **照真实案件**，甚至照真实的一审/二审差异设计判决档位 |
| 人物姓名、地名、单位名、具体金额 | **全部化名/微调** |
| 复盘页 | 明确写出"本案原型：XX 案（（20XX）X刑终X号）"，附一段延伸阅读，说明真实结果与法律意义 |
| README / 宣传 | **可以大方用真名**："从许霆案到于欢案，18 个真实案件改编" |

这样：宣传拿到了知名度，游戏内没有消费任何具体的人，复盘页反而给了真实案件应有的尊重——**玩完一关知道这案子真实发生过、真实的人真的坐了牢或者真的被改判无罪，这份重量是虚构案件给不了的。**

### 2.2 案件分级与处理规格

| 级 | 特征 | 处理 |
|---|---|---|
| **A 级** | 已终审多年、判决被广泛讨论、多为法学教学经典，社会共识倾向"这案子值得被记住"（多为改判/纠错案例） | 骨架照搬，人物化名，**复盘页明示原型与文号** |
| **B 级** | 案情惨烈、被害人家属仍在、当事人多已被执行死刑（药家鑫、复旦投毒、张扣扣、保姆纵火等） | **做，但按 2.2.1 的六条规格** |
| **C 级** | 涉政、涉黑保护伞、性犯罪、涉未成年人性侵、正在审理中的案件 | 一律不做 |

> 冤案平反类（呼格吉勒图、聂树斌）从 C 级移出，改为 **B 级候选**——这两案已由法院公开纠错、官方定性明确，做"再审阶段的辩护人"叙事极强。若做，只走证据链的技术层面（口供与现场不符、鉴定问题），不写刑讯细节，不涉及任何办案人员。放在最后一关，做到 B13 时再定。

#### 2.2.1 B 级案件的六条硬规格

B 级案子的戏在于**辩护的伦理困境**，不在于惨案本身。这六条是把"消费惨案"和"直面困境"分开的那条线：

1. **化名之外还要改可识别细节**。时间、地点、数量、职业、凶器全部改动，保证不能与真实案件逐条对应。A 级只需化名，B 级要做到"读得出是哪一类案子，对不上是哪一个案子"。
2. **复盘页不明示原型**。A 级写"本案原型：许霆案（文号）"，B 级只写"现实中同类案件的处理是……"，不点名。
3. **不写作案过程**。案情只以鉴定意见、笔录、证言的形式出现在卷宗里，不做叙述性描写，不给现场 CG。
4. **被害人一方必须有分量**。B 级案件强制配置附带民事诉讼原告人（被害人家属）出庭，他们的陈述要写得站得住——写得比被告人的辩解更有力才算过关。**如果一个案子里只有玩家在为被告人开脱，那就是在消费死者。**
5. **良心轨权重加倍**，且没有无罪结局。B 级案件的最好结局是死缓或无期。你赢不了，你只能让他不死。
6. **复盘页必须告知现实结果**。"现实中，与本案类似的被告人被执行了死刑。"这一句不能省。

这六条也是这类案子好玩的原因——**它逼你面对"你在替谁说话"这个问题，而不是让你爽。**

### 2.4 判决分布：不能打得好就一定赢

对照真实结果设计判决档位。20 案里：

- **最好结局是无罪 / 不起诉**：约 6 个（06 收玉米、07 代购、13 平反、05 听证、19 我的脸、17 电梯）
- **最好结局仍是有罪，只是刑期不同**：约 10 个（01 02 03 04 08 09 10 11 12，加两个 B 级）
- **最好结局是部分支持**：4 个民事 / 行政
- **两个 B 级案件不设无罪结局**。最好的结果是死缓。你赢不了，你只能让他不死。

这是这个游戏的重量。**你打得再好，有些人还是要坐牢，有些人还是要死。**这不是设计缺陷，是它想说的话。

## 三、GitHub 上能直接用的资源

搜了一圈，真正能用的是**法条**，不是案例数据集。

### 3.1 采用：法条全文（做游戏内"法条速查"）

| 仓库 | 内容 | 我们怎么用 |
|---|---|---|
| [lawtext/laws](https://github.com/lawtext/laws) | 2000+ 部国家法律法规，Markdown，源自官方[国家法律法规数据库](https://flk.npc.gov.cn) | **首选**。数据源最权威 |
| [LawRefBook/Laws](https://github.com/LawRefBook/Laws) | 同类，按宪法/刑法/民法典/行政法/司法解释分目录，带更新脚本与 SQLite 生成 | 备选，目录结构更好抓 |

**版权**：法律法规属《著作权法》第五条排除对象，**不受著作权保护**，可自由使用。致谢仍要在 README 写。

## 四、输入：文字与语音并列

按你的要求，两条路平等，不是主从：

- 输入区下方**两个等宽按钮**：`发言`（提交文字）和 `按住说话`（语音）。语音不是输入框角落里的小话筒图标。
- 语音识别的结果**落进同一个输入框**，可以继续用键盘改，改完再提交。**语音永不自动提交**。
- 页内语音（Web Speech API）**不可用时**（`file://` 打开、国内 Chrome 连不上 Google、拒绝麦克风权限），按钮换成一行常驻提示："用输入法的话筒键口述，效果更好。"——**不藏起来，明确告诉玩家还有一条路**。
- iOS 键盘话筒键 / macOS 连按两下 Fn 的说明写进新手引导第二屏。

技术细节见 `施工规范与流程-v2.md` 第四节。

## 五、生涯外壳（一期范围不变）

- 接案：3 选 1，卡片上标难度、预估律师费、当事人是否配合、案件类型
- 三轨：**声誉**（决定能接到什么案）、**金钱**（律所房租、调查取证要花钱、名案带来的溢价）、**良心**
- 良心轨的设计原则不变：**扣分的不是"你替坏人说话"**（有罪的人也有获得辩护的权利，这是制度不是瑕疵），扣分的是**你对当事人的背叛**——隐瞒不利后果、承诺你做不到的事、为了胜率牺牲他的利益。
- 一期不做：事务所经营、雇人、合伙人升迁、多线剧情。
